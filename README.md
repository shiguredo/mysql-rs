## 概要

`mysql-rs` は MySQL クライアントの Rust 実装です。

- `shiguredo_mysql` - Sans I/O な MySQL プロトコル実装
- `shiguredo_tokio_mysql` - tokio 上で動作する非同期 MySQL クライアント
